# Programming Language RPG — C++ Prototype

This is a **C++ prototype** for my programming-language-themed RPG game.

The purpose of this prototype is to test and validate the game's core battle system and code-block mechanics before implementing the full game in **Godot**.

The prototype focuses on:

* Turn-based battles
* Code blocks and their interactions
* Player and enemy actions
* Basic game and battle logic

This is **not the final game**. It is a small-scale prototype used to experiment with the mechanics and structure that will later be recreated and expanded in Godot.
